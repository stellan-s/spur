# Completion report

Return a compact report in the user's language with:

1. selected Spur organization;
2. repository and pinned commit;
3. installed skill version and, when available, the reported Claude model;
4. whether uncommitted work was absent or explicitly ignored;
5. counts returned by the completed source-analysis run;
6. modeled layers and intentionally unsupported layers;
7. reused existing objects and avoided duplicates when known;
8. remaining knowledge gaps or ambiguities;
9. the model review URL when it can be derived safely from the workspace;
10. the mandatory Spur beta notice.

Do not turn the report into an assessment of application, API, architecture, codebase, vendor, or team quality. Report what was modeled and what could not be established.
